Shared design notes for the auth emails in this folder.

Email clients are not browsers. These templates therefore use tables for
layout, inline styles only, no web fonts, and no external assets, which is
what survives Outlook, Gmail's clipping and dark-mode inversion.

Every template keeps the same shape: a wordmark, one sentence saying what
happened, one button, the raw link for clients that strip buttons, and a line
telling the reader what to do if they did not expect the message. The action
is always a single obvious target.
